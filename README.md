# PLDMGR_JSON

Custom payload repository for PS5 Payload Manager.

Payload sources are automatically refreshed every 2 hours using GitHub Actions. The generated `payloads.json` contains validated payload download URLs and metadata.

## Adding this source

Open the Payload Manager dashboard on your PS5:

1. Go to **Settings → Manage Sources**
2. Click **Add Source**
3. Paste **one** of the following URLs:

### GitHub Raw

```text
https://raw.githubusercontent.com/diegoweb/PLDMGR_JSON/main/payloads.json
```

### GitHub Pages

```text
https://diegoweb.github.io/PLDMGR_JSON/payloads.json
```

These are alternative URLs pointing to the same generated catalog. You normally only need to add one.

## For maintainers

### Adding a payload

Edit [`links.txt`](links.txt). One entry per line; `github:owner/repo` points at that repo's latest release, and optional pipe-separated fields add category, description, version and `key=value` overrides:

```text
github:quer3q/kraken-mount
github:quer3q/kraken-mount | Tools | Kraken USB mount | v0.1.0-beta
github:quer3q/kraken-mount | Tools | Kraken USB mount | v0.1.0-beta | icon=https://raw.githubusercontent.com/quer3q/kraken-mount/main/docs/logo.png
```

`payloads.json` and `icons.json` are regenerated by GitHub Actions on every change to `links.txt`/`generate.py` and once a day.

### Icons

`PS5 Payload Manager` reads icons from `icons.json`, which stores each image inline as a data URI and is capped at **12,288 characters per icon** by PS5 WebKit. The generator picks, in order:

1. An `icon=` override in `links.txt`.
2. The best image found in the repo itself — its default branch is scanned for anything named like an icon, logo or banner (`icon0`, `icon`, `logo`, `avatar`, `brand`, `banner`, …), wherever it lives (`ps5/icon0.png`, `sce_sys/icon0.png`, `docs/logo.png`, …). Images below 48px, screenshots, QR codes and splash art are ignored. A project banner beats the owner's avatar.
3. Images the repo README displays, scored the same way.
4. The repo owner's GitHub avatar.
5. A generated letter tile, so nothing is ever iconless.

Larger images are downscaled to 128px with Pillow and re-encoded (PNG, palette PNG, or JPEG) until they fit the limit; non-square art is center-cropped, and a wide banner is drawn whole over a blurred copy of itself so it fills the tile without losing anything. Pillow comes from [`requirements.txt`](requirements.txt); without it oversized images fall back to the letter tile.

To pin a specific logo, add `icon=` to the line in `links.txt`:

```text
# any direct image URL
github:quer3q/kraken-mount | icon=https://raw.githubusercontent.com/quer3q/kraken-mount/main/docs/logo.png

# a GitHub file page URL works too (converted to raw automatically)
github:quer3q/kraken-mount | icon=https://github.com/quer3q/kraken-mount/blob/main/docs/logo.png

# the owner's avatar
github:quer3q/kraken-mount | icon=@quer3q

# no icon at all
github:quer3q/kraken-mount | icon=none
```

### Running locally

```bash
pip install -r requirements.txt
python generate.py
```

Set `GITHUB_TOKEN` to a personal access token to avoid GitHub's unauthenticated API rate limit (60 requests/hour), and `REPO_NAME` to change the catalog title.
